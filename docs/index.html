devopsjira-mcp

MCP server that connects GitHub Copilot to DevOps Jira. 62 tools — full issue lifecycle, sprint management, epics, JSM service desk, bulk ops, and more. Built in Go for ~30ms cold start with automatic retry. No destructive operations — delete is disabled by design.

GitHub ↗ | Create PAT ↗ | Go 1.24 MCP v1.0 62 tools No Delete

Quick Start

1. Create a Personal Access Token

Go to DevOps Jira → Profile → Personal Access Tokens and generate a new token.

2. Clone & build

git clone https://github.deutsche-boerse.de/at384/devopsjira-mcp.git
cd devopsjira-mcp
go build -o devopsjira-mcp.exe .
# Build output:
devopsjira-mcp.exe (~12MB, zero dependencies)

# Cold start: ~30ms
# HTTP/2 connection pooling, 30 idle conns
# Auto-retry on 429/5xx with exponential backoff
# Single binary — no Python, no venv, no pip

3. Add to VS Code mcp.json

{
  "servers": {
    "devopsjira": {
      "command": "C:/path/to/devopsjira-mcp.exe",
      "env": {
        "DEVOPSJIRA_URL": "https://devopsjira.deutsche-boerse.com",
        "DEVOPSJIRA_PAT": "your-token-here"
      },
      "type": "stdio"
    }
  }
}

4. Reload VS Code

Ctrl+Shift+P → Developer: Reload Window. The devopsjira server appears in your MCP list. Done.

Note: Config lives at %APPDATA%\Code\User\mcp.json. Once set up, it works from any workspace.

Why Use This

Do everything you do in DevOps Jira — from VS Code chat. No context switching. 65 tools covering the full Jira API.

Full issue lifecycle

Create, search, assign, transition, comment, close, archive. JQL for anything. Bulk operations across multiple issues at once. No delete — data is never destroyed.

Sprint & Agile management

Create sprints, move issues, start/complete sprints, get velocity, rank backlog items, manage epics.

JSM Service Desk

Create requests, check SLA timers, get approvals, manage queues — full portal operations without a browser.

Blazing fast & reliable

Go binary with HTTP/2, connection pooling, auto-retry on rate limits and server errors. TLS skip for Zscaler.

Architecture

┌─────────────┐    stdio/JSON-RPC    ┌──────────────────────┐    HTTPS + PAT    ┌────────────────────────────────────┐
│  VS Code    │ ◄──────────────────► │  devopsjira-mcp      │ ◄──────────────► │  DevOps Jira                       │
│  Copilot    │                      │  (Go binary, 12MB)   │                  │  devopsjira.deutsche-boerse.com    │
└─────────────┘                      └──────────────────────┘                  └────────────────────────────────────┘
                                              │
                                              ├── Jira REST API v2 (issues, projects, users)
                                              ├── Agile API (boards, sprints, epics, ranking)
                                              └── JSM Service Desk API (requests, SLA, queues)

Transport

stdio — VS Code spawns the binary, communicates via JSON-RPC over stdin/stdout.

Auth

Personal Access Token — Bearer header. Long-lived, no refresh needed.

Reliability

Auto-retry (3x) on network errors, 429 rate limits, and 5xx server errors with exponential backoff.

Performance

~30ms cold start. HTTP/2 with 30 idle connections. TLS skip for Zscaler interception.

Security Design

This server is hardened against accidental or malicious data destruction:

No DELETE operations

The HTTP DELETE method is completely removed from the client. No tool can permanently destroy issues, comments, attachments, or any Jira data.

No remove tools

Tools that previously removed watchers or labels have been eliminated. Data can only be added or modified, never removed.

raw_api_call restricted

The raw API escape hatch only supports GET, POST, and PUT. DELETE requests are rejected at the handler level.

Archive, not delete

The worst destructive action possible is transitioning an issue to “Archived” status — which is fully reversible.

Troubleshooting

Server not showing?

Ctrl+Shift+P → MCP: Reset All Cached MCP Servers, then reload window.

401 Unauthorized?

Your PAT may have expired. Generate a new one at Profile → Tokens.

403 Forbidden?

PAT needs project permissions. Ensure it has access to the project/board you're targeting.

Connection error?

Ensure you're on the corporate network. TLS skip is enabled for Zscaler. Check JIRA_PROXY if behind additional proxy.
